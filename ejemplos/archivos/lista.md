# Checklist de la practica

- [ ] `terraform apply` y anotar los tres nombres de bucket
- [ ] `aws s3 ls` y ver los tres buckets listados
- [ ] Sincronizar los archivos de ejemplo a cada bucket
- [ ] Abrir la URL del sitio estatico en el navegador
- [ ] Pegar la URL de un objeto del bucket privado y ver el `Access Denied`
- [ ] Crear la tabla externa en Athena y consultarla
- [ ] Mirar `resultados/` y ver que cada consulta dejo un CSV nuevo
- [ ] `aws s3 rm` sobre un objeto y confirmar que no hay vuelta atras
- [ ] `terraform destroy` al final
