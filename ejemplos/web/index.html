Esto sale de un bucket.

No hay servidor web, ni EC2, ni contenedor. Este HTML es un objeto en S3 y lo estás viendo porque el bucket tiene website configuration y una bucket policy que permite s3:GetObject a todo internet.

  • index.html — este archivo, el documento índice del bucket
  • estilos.css — otro objeto más, pedido por el navegador
  • error.html — probá una URL que no exista y aparece

La URL termina en s3-website-us-east-1.amazonaws.com, no en s3.amazonaws.com: son dos endpoints distintos. El de website resuelve index.html y las páginas de error; el otro devuelve objetos crudos.

Y es http://, sin la s. El website endpoint de S3 no hace TLS: para eso hace falta CloudFront adelante.
